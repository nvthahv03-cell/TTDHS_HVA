/** * ============================================================================== * TRUNG TÂM QUẢN TRỊ SỐ HVA - TRƯỜNG THPT HÒA VANG * BACKEND CHUYÊN BIỆT: ĐIỀU HÀNH SỐ (TTDHS ENGINE v3.0) * TÍCH HỢP HOÀN CHỈNH VỚI HVA_PERSONNEL.JS & TTPHATHANH.HTML * ============================================================================== */ const TTDHS_CONFIG = { SPREADSHEET_ID: "19zyS6na6VaTiTImj9Bh11ot6f75TmBBpECAMxiObJcA", SHEET_NHAN_SU: "Du_lieu_NhanSu_THPT_HOA_VANG", SHEET_PHAT_HANH: "TTDHS_PHAT_HANH", SHEET_PHAN_HOI: "TTDHS_PHAN_HOI" }; // ============================================================================== // 1. ROUTER TRUNG TÂM ĐIỀU HÀNH SỐ (doGet & doPost) // ============================================================================== function doGet(e) { try { const params = (e && e.parameter) ? e.parameter : {}; const action = String(params.action || "").trim(); // --- TUYẾN 1: TƯƠNG THÍCH VỚI HVA_PERSONNEL.JS --- if (action === "searchNhanSuQuick") { return dhsSearchNhanSuQuick_(params); } if (action === "getPersonnelWorkgroups") { return dhsGetPersonnelWorkgroups_(); } if (action === "getDanhSachTo") { return dhsGetDanhSachTo_(); } if (action === "getNhanSuTheoTo") { return dhsGetNhanSuTheoTo_(params); } // --- TUYẾN 2: LẤY CHI TIẾT BẢN PHÁT HÀNH (KHẢO SÁT, HỌP, NHIỆM VỤ) --- if (action === "getPublicationDetailV3" || action === "getSurveyConfig") { return dhsGetPublicationDetail_(params); } // --- TUYẾN 3: BÁO CÁO THỐNG KÊ TIẾN ĐỘ --- if (action === "getPublicationMetrics" || action === "getSurveyReport") { return dhsGetPublicationMetrics_(params); } return dhsJSON_({ success: false, message: "Action GET không hợp lệ: " + action }); } catch (err) { return dhsJSON_({ success: false, message: err.toString() }); } } function doPost(e) { try { let payload = {}; if (e && e.postData && e.postData.contents) { try { payload = JSON.parse(e.postData.contents); } catch (_) { payload = e.parameter || {}; } } else if (e && e.parameter) { payload = e.parameter; } const action = String(payload.action || "").trim(); // 1. BGH / TTCM kích hoạt phát hành văn bản, khảo sát, nhiệm vụ if (action === "publishDocument" || action === "publishDocuments") { return dhsPublishDocument_(payload); } // 2. Giáo viên gửi kết quả: Khảo sát, Bình chọn Zalo, Báo cáo số liệu if (action === "submitSurveyPollResponse" || action === "submitSurveyResponse") { return dhsSubmitResponse_(payload); } // 3. Giáo viên xác nhận cuộc họp / Xin vắng if (action === "confirmMeetingAttendance" || action === "requestMeetingAbsence") { return dhsProcessMeetingAction_(payload); } return dhsJSON_({ success: false, message: "Action POST không hợp lệ: " + action }); } catch (err) { return dhsJSON_({ success: false, message: err.toString() }); } } // ============================================================================== // 2. HỆ THỐNG TIỆN ÍCH DÙNG CHUNG // ============================================================================== function dhsJSON_(data) { return ContentService.createTextOutput(JSON.stringify(data)) .setMimeType(ContentService.MimeType.JSON); } function dhsGetSheet_(sheetName) { const ss = SpreadsheetApp.openById(TTDHS_CONFIG.SPREADSHEET_ID); let sheet = ss.getSheetByName(sheetName); if (!sheet) { sheet = ss.insertSheet(sheetName); if (sheetName === TTDHS_CONFIG.SHEET_PHAT_HANH) { sheet.appendRow([ "Thời gian phát hành", "Mã phát hành", "Mã tài liệu", "Module nguồn", "Loại", "Tiêu đề", "Người phát hành", "Thời hạn", "Điểm đến", "Số người nhận", "Chi tiết Payload (JSON)" ]); } else if (sheetName === TTDHS_CONFIG.SHEET_PHAN_HOI) { sheet.appendRow([ "Thời gian phản hồi", "Mã phát hành", "Mã tài liệu", "Tên đăng nhập", "Họ và tên", "Tổ bộ phận", "Trạng thái", "Nội dung phản hồi (JSON)" ]); } } return sheet; } // ============================================================================== // 3. TƯƠNG THÍCH CHUẨN XÁC VỚI HVA_PERSONNEL.JS CORE // ============================================================================== function dhsSearchNhanSuQuick_(params) { const category = String(params.category || "").trim().toUpperCase(); const q = String(params.q || "").trim().toLowerCase(); const ss = SpreadsheetApp.openById(TTDHS_CONFIG.SPREADSHEET_ID); const sh = ss.getSheetByName(TTDHS_CONFIG.SHEET_NHAN_SU); if (!sh) return dhsJSON_({ success: true, data: [] }); const lastRow = sh.getLastRow(); const lastCol = Math.max(25, sh.getLastColumn()); if (lastRow < 7) return dhsJSON_({ success: true, data: [] }); // Tiêu đề dòng 6, dữ liệu từ dòng 7 const displayData = sh.getRange(7, 1, lastRow - 6, lastCol).getDisplayValues(); const rawData = sh.getRange(7, 1, lastRow - 6, lastCol).getValues(); const results = []; for (let r = 0; r < displayData.length; r++) { const maGV = String(displayData[r][1] || "").trim(); // Cột B: Mã nhân sự const hoTen = String(displayData[r][2] || "").trim(); // Cột C: Họ tên const chucVu = String(displayData[r][9] || "").trim(); // Cột J: Vị trí / Chức vụ const toBoPhan = String(displayData[r][12] || "").trim(); // Cột M: Tổ const monDay = String(displayData[r][13] || "").trim(); // Cột N: Môn const username = String(displayData[r][14] || "").trim(); // Cột O: Username // Nhận diện lớp GVCN (cột W - index 22) let lop = String(displayData[r][22] || rawData[r][22] || "").trim(); if (lop.startsWith("Date(")) { const m = lop.match(/Date\((\d+),(\d+),(\d+)\)/); if (m) { const mon = parseInt(m[2], 10) + 1; const day = parseInt(m[3], 10); lop = (day >= 10 && day <= 12) ? (day + "/" + mon) : (mon + "/" + day); } } lop = lop.replace(/\s+/g, ""); const personObj = { username: username || maGV, maGV: maGV, hoTen: hoTen, chucVu: chucVu || "Giáo viên", viTriViecLam: chucVu || "Giáo viên", to: toBoPhan, toBoPhan: toBoPhan, tenTo: toBoPhan, monDay: monDay, lopChuNhiem: lop, nhomCongTac: { GVCN: lop ? "GVCN " + lop : "" } }; if (!hoTen) continue; // Lọc theo Category của HVAPersonnel.search let isMatch = false; if (category === "BGH") { isMatch = toBoPhan.toLowerCase().includes("ban giám hiệu") || toBoPhan.toLowerCase() === "bgh" || chucVu.toLowerCase().includes("hiệu trưởng"); } else if (category === "CHIBO") { isMatch = chucVu.toLowerCase().includes("bí thư") || chucVu.toLowerCase().includes("chi ủy") || toBoPhan.toLowerCase().includes("chi bộ"); } else if (category === "TEAM") { const targetTeam = q.toLowerCase(); const currentTeam = toBoPhan.toLowerCase(); isMatch = currentTeam === targetTeam || currentTeam.includes(targetTeam) || targetTeam.includes(currentTeam); } else if (category === "WORKGROUP") { if (q.toUpperCase() === "GVCN") { isMatch = Boolean(lop && /^1[012]\/\d{1,2}$/.test(lop)); } else { isMatch = chucVu.toLowerCase().includes(q) || toBoPhan.toLowerCase().includes(q); } } else { // Tìm kiếm tự do theo từ khóa isMatch = !q || hoTen.toLowerCase().includes(q) || username.toLowerCase().includes(q) || toBoPhan.toLowerCase().includes(q); } if (isMatch) { results.push(personObj); } } return dhsJSON_({ success: true, data: results, results: results }); } function dhsGetPersonnelWorkgroups_() { return dhsJSON_([ { name: "GVCN" }, { name: "Tổ trưởng chuyên môn" }, { name: "Đoàn thanh niên" }, { name: "Công đoàn" } ]); } function dhsGetDanhSachTo_() { const ss = SpreadsheetApp.openById(TTDHS_CONFIG.SPREADSHEET_ID); const sh = ss.getSheetByName(TTDHS_CONFIG.SHEET_NHAN_SU); if (!sh) return dhsJSON_([]); const lastRow = sh.getLastRow(); if (lastRow < 7) return dhsJSON_([]); const teams = sh.getRange(7, 13, lastRow - 6, 1).getDisplayValues(); const set = new Set(); teams.forEach(t => { const val = String(t[0] || "").trim(); if (val) set.add(val); }); const res = Array.from(set).map(t => ({ tenTo: t, label: t })); return dhsJSON_(res); } function dhsGetNhanSuTheoTo_(params) { const toTarget = String(params.to || "").trim().toLowerCase(); const ss = SpreadsheetApp.openById(TTDHS_CONFIG.SPREADSHEET_ID); const sh = ss.getSheetByName(TTDHS_CONFIG.SHEET_NHAN_SU); if (!sh) return dhsJSON_([]); const lastRow = sh.getLastRow(); if (lastRow < 7) return dhsJSON_([]); const data = sh.getRange(7, 1, lastRow - 6, 15).getDisplayValues(); const list = []; for (let r = 0; r < data.length; r++) { const to = String(data[r][12] || "").trim(); if (!toTarget || to.toLowerCase() === toTarget) { list.push({ maGV: String(data[r][1] || "").trim(), hoTen: String(data[r][2] || "").trim(), chucVu: String(data[r][9] || "Giáo viên").trim(), to: to, tenTo: to, monDay: String(data[r][13] || "").trim(), username: String(data[r][14] || "").trim() }); } } return dhsJSON_(list); } // ============================================================================== // 4. KÍCH HOẠT PHÁT HÀNH TẬP TRUNG (TTPhatHanh.html) // ============================================================================== function dhsPublishDocument_(payload) { const publishId = String(payload.publishId || payload.batchPublishId || ("PH-" + Utilities.formatDate(new Date(), "GMT+7", "yyyyMMdd-HHmmss"))).trim(); const moduleSource = String(payload.moduleSource || "DieuHanhSo").trim(); const document = payload.document || {}; const docId = String(document.docId || payload.docId || "").trim(); const title = String(document.title || payload.title || "Tài liệu phát hành").trim(); const type = String(payload.documentType || document.type || "THONG_BAO").trim(); const sender = payload.sender || {}; const senderName = String(sender.fullName || sender.username || "Ban Giám hiệu").trim(); const rawData = payload.data || (payload.documents && payload.documents[0] && payload.documents[0].data) || {}; const deadline = [rawData.deadlineDate, rawData.deadlineTime].filter(Boolean).join(" "); const destinations = Array.isArray(payload.destinations) ? payload.destinations.map(d => d.name || d.id || d).join(", ") : ""; const recipients = Array.isArray(payload.recipients) ? payload.recipients : []; const sheet = dhsGetSheet_(TTDHS_CONFIG.SHEET_PHAT_HANH); const now = Utilities.formatDate(new Date(), "Asia/Ho_Chi_Minh", "dd/MM/yyyy HH:mm:ss"); const row = [ now, publishId, docId, moduleSource, type, title, senderName, deadline, destinations, recipients.length, JSON.stringify(payload) ]; sheet.appendRow(row); return dhsJSON_({ success: true, message: "Kích hoạt phát hành số thành công.", publishId: publishId, documentCount: Array.isArray(payload.documents) ? payload.documents.length : 1 }); } // ============================================================================== // 5. LẤY CHI TIẾT BẢN PHÁT HÀNH & CÂU HỎI // ============================================================================== function dhsGetPublicationDetail_(params) { const publishId = String(params.publishId || params.id || "").trim(); const username = String(params.username || "").trim().toLowerCase(); if (!publishId) { return dhsJSON_({ success: false, message: "Thiếu mã phát hành." }); } const sheetPH = dhsGetSheet_(TTDHS_CONFIG.SHEET_PHAT_HANH); const lastRowPH = sheetPH.getLastRow(); let foundPayload = null; if (lastRowPH >= 2) { const data = sheetPH.getRange(2, 2, lastRowPH - 1, 10).getValues(); for (let i = data.length - 1; i >= 0; i--) { const pId = String(data[i][0] || "").trim(); const dId = String(data[i][1] || "").trim(); if (pId === publishId || dId === publishId) { try { foundPayload = JSON.parse(data[i][9]); } catch (_) {} break; } } } if (!foundPayload) { return dhsJSON_({ success: false, message: "Không tìm thấy nội dung phát hành với mã: " + publishId }); } let userResponse = null; if (username) { const sheetResp = dhsGetSheet_(TTDHS_CONFIG.SHEET_PHAN_HOI); const lastRowResp = sheetResp.getLastRow(); if (lastRowResp >= 2) { const dataResp = sheetResp.getRange(2, 2, lastRowResp - 1, 7).getValues(); for (let j = dataResp.length - 1; j >= 0; j--) { const rPubId = String(dataResp[j][0] || "").trim(); const rDocId = String(dataResp[j][1] || "").trim(); const rUser = String(dataResp[j][2] || "").trim().toLowerCase(); if ((rPubId === publishId || rDocId === publishId) && rUser === username) { try { userResponse = { updatedAt: dataResp[j][0], status: dataResp[j][5], answers: JSON.parse(dataResp[j][6]) }; } catch (_) {} break; } } } } return dhsJSON_({ success: true, publishId: publishId, payload: foundPayload, document: foundPayload.document || {}, sender: foundPayload.sender || {}, myResponse: userResponse }); } // ============================================================================== // 6. TIẾP NHẬN PHẢN HỒI (KHẢO SÁT, BÌNH CHỌN, BÁO CÁO) // ============================================================================== function dhsSubmitResponse_(payload) { const username = String(payload.username || "").trim().toLowerCase(); const publishId = String(payload.publishId || payload.surveyId || "").trim(); const status = String(payload.status || "ĐÃ HOÀN THÀNH").trim(); if (!username || !publishId) { return dhsJSON_({ success: false, message: "Thiếu thông tin tài khoản hoặc mã phát hành." }); } const sheet = dhsGetSheet_(TTDHS_CONFIG.SHEET_PHAN_HOI); const lock = LockService.getScriptLock(); if (!lock.tryLock(15000)) { return dhsJSON_({ success: false, message: "Máy chủ đang xử lý dữ liệu khác, vui lòng thử lại sau giây lát." }); } try { const lastRow = sheet.getLastRow(); let rowFound = 0; if (lastRow >= 2) { const data = sheet.getRange(2, 2, lastRow - 1, 3).getValues(); for (let i = 0; i < data.length; i++) { const rPubId = String(data[i][0] || "").trim(); const rDocId = String(data[i][1] || "").trim(); const rUser = String(data[i][2] || "").trim().toLowerCase(); if ((rPubId === publishId || rDocId === publishId) && rUser === username) { rowFound = i + 2; break; } } } const now = Utilities.formatDate(new Date(), "Asia/Ho_Chi_Minh", "dd/MM/yyyy HH:mm:ss"); const fullName = String(payload.fullName || payload.hoTen || username).trim(); const team = String(payload.department || payload.toBoPhan || "").trim(); const answersStr = JSON.stringify(payload.answers || payload.data || {}); const row = [ now, publishId, String(payload.docId || publishId), username, fullName, team, status, answersStr ]; if (rowFound > 0) { sheet.getRange(rowFound, 1, 1, row.length).setValues([row]); } else { sheet.appendRow(row); } return dhsJSON_({ success: true, message: "Ghi nhận phản hồi thành công.", updatedAt: now, status: status }); } finally { lock.releaseLock(); } } // ============================================================================== // 7. XÁC NHẬN THAM DỰ CUỘC HỌP / XIN VẮNG // ============================================================================== function dhsProcessMeetingAction_(payload) { const action = String(payload.action || "").trim(); const username = String(payload.username || "").trim().toLowerCase(); const meetingId = String(payload.meetingId || payload.publishId || "").trim(); if (!username || !meetingId) { return dhsJSON_({ success: false, message: "Thiếu thông tin cuộc họp hoặc tài khoản." }); } const isAbsence = action === "requestMeetingAbsence"; const status = isAbsence ? "XIN VẮNG" : "THAM DỰ"; const detail = isAbsence ? { reason: String(payload.reason || "").trim() } : { confirmed: true }; return dhsSubmitResponse_({ username: username, publishId: meetingId, docId: meetingId, fullName: String(payload.fullName || username), status: status, answers: detail }); } // ============================================================================== // 8. THỐNG KÊ TIẾN ĐỘ THỰC HIỆN CẤP TRƯỜNG // ============================================================================== function dhsGetPublicationMetrics_(params) { const publishId = String(params.publishId || params.id || "").trim(); if (!publishId) return dhsJSON_({ success: false, message: "Thiếu mã phát hành." }); const sheetResp = dhsGetSheet_(TTDHS_CONFIG.SHEET_PHAN_HOI); const lastRow = sheetResp.getLastRow(); const responses = []; if (lastRow >= 2) { const data = sheetResp.getRange(2, 1, lastRow - 1, 8).getValues(); for (let i = 0; i < data.length; i++) { const pId = String(data[i][1] || "").trim(); const dId = String(data[i][2] || "").trim(); if (pId === publishId || dId === publishId) { responses.push({ time: data[i][0], username: data[i][3], fullName: data[i][4], team: data[i][5], status: data[i][6], answers: data[i][7] }); } } } return dhsJSON_({ success: true, publishId: publishId, totalResponses: responses.length, responses: responses }); }
